# 中文图谱与本体确认流程

## 本次调整

- 本地 `.env` 的 `SUMMARY_LANGUAGE` 从 English 改为 Chinese；示例配置同步更新。需要重启后端生效。
- 抽取优先遵循项目本体的语言；中文本体要求名称、关系、关键词和描述使用中文，保留必要的编号与缩写。
- 默认本体、导入模板及兜底类型改用中文；兼容读取旧的 Other，允许在编辑器中改为“其他”。
- 自动建立的图像、表格、公式附件节点使用中文显示名称和关系说明；内部标识保持稳定。
- 项目文档上传后只解析和保存资料，显示“已解析，待确认本体”。解析后的资料可以辅助生成本体和项目简介。
- 在文档页点击“构建中文图谱”，核对已保存的本体后确认。后端校验项目归属、本体版本、中文类型和完整的文档块，再进行抽取与索引。
- 手动构建参与现有流水线互斥，避免与删除、清空并发。失败保留解析资料，可重试；部分文档已成功时，重试处理剩余待构建文档。

## 使用方法

1. 重启服务，刷新页面。
2. 上传资料，等待解析完成。
3. 在本体页选取资料生成中文草稿，检查并保存。旧英文类型需转换为中文，兜底类型用“其他”。
4. 返回文档页，点击“构建中文图谱”，确认本体后开始。

## 已有数据与验证

已有英文图谱不会自动翻译或覆盖。需要保留旧项目时，建议新建项目重新上传并按上述流程构建；没有执行任何用户数据删除或迁移。
