# 2026-10-29 修改与提交验证

## 功能与修复

- 本体支持从选定的项目文档生成草稿；草稿校验、采纳和保存分离，保留已有本体身份及版本校验。
- 项目名称、简介等信息可以编辑；简介可以根据现有解析文件生成，确认后保存。
- 项目上传仅解析并保留材料，确认已保存的中文本体后手动构建图谱；校验文档块完整性，接入流水线互斥及等待任务恢复。
- 中文本体控制实体、关系及描述语言；默认模板、兜底类型和附件显示名称中文化。
- MinerU 每次解析持有独立 HTTP session，避免并发关闭连接；上传解析失败不再返回虚假成功。
- 文档预览、下载正确处理序列化路径；重命名副本仅在原项目目录内按数字后缀查找，防止取错其他文件。
- 本体生成移除固定 4000-token 限制，沿用模型配置；空响应日志记录结束原因与用量，不记录资料或推理正文。
- 图谱描述的内部 `<SEP>` 在展示层转换为换行。
- 项目问答页 Markdown 样式完善；think 内容折叠显示，处理分片标签、多段思考及代码内字面标签；历史对话只发送最终答案。
- 更新两项过时的本体测试，使其使用隔离存储及当前 OntologySpec 接口。
