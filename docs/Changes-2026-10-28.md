# Change record: 2026-10-28

## Scope

Single-host deployment for users on a trusted LAN. Existing authentication
behavior is unchanged, as requested. No remote push or deployment is included.

## Changes

- Pin the project Python version to 3.12 for the uv environment.
- Adjust the project homepage title, subtitle, search, spacing, statistics and
  view controls to match the supplied screenshot.
- Separate project/ontology metadata from the disposable LLM response cache.
  Migrate legacy records by flushing the destination before deleting originals.
  Metadata uses host-local JSON independently of the configured RAG backend.
- Add public prefix reads to JSON, MongoDB, Redis and PostgreSQL KV adapters.
- Scope answer caches, document/chunk IDs, uploads and file deletion by project.
  Read all document pages; invalid project filters return errors.
- Serialize asset metadata updates across instances and write files atomically.
- Repair entity operations and frontend search parameters; use core entity
  mutations so graph and vector records remain synchronized.
- Add official MinerU cloud parsing with signed uploads, polling, safe ZIP
  extraction and isolated assets; repair self-hosted parser initialization.
- Repair initialized-parser configuration collection, chunk metadata recovery,
  multimodal tables/attachments and NanoVectorDB project filtering.
- Add regression, provider-contract and application pipeline tests. Remove
  test-module mock pollution without changing authentication implementation.

## Local configuration

The ignored `.env` uses the existing DeepSeek model configuration, Ollama's
OpenAI-compatible embedding endpoint with `embeddinggemma-2:latest` (768
dimensions), and `mineru_cloud`. The user-provided MinerU token is saved only
there. No real credential belongs in tracked files.

Restart the service to load configuration and migrate metadata. Back up the
working directory, including `kv_store_project_metadata.json` in the configured
workspace. Existing document/chunk IDs are not rewritten. Collections created
with another embedding model or dimension need reindexing before reuse.
